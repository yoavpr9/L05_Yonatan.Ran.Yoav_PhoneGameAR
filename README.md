# שריפה בכיתה: משחק AR לטלפון

משחק מציאות רבודה שרץ בדפדפן של טלפון אנדרואיד (Chrome), בלי התקנה. המשחק משתמש במצלמה האחורית ובחיישני התנועה של הטלפון.

## מהלך המשחק

1. **הדלת**: סורקים את ידית הדלת. הדלת "נפתחת" וחץ מוביל פנימה. אחרי שנכנסים לכיתה לוחצים "נכנסתי לכיתה".
2. **חוש הסכנה**: ברקים אדומים וכחולים מצידי המסך ופעימות לב שהולכות ומואצות (וגם כשמתקרבים למזגן).
3. **המזגן**: כשסורקים את המזגן הוא מעלה עשן, ואחרי כמה שניות עולה באש שהולכת ומתגברת.
4. **עמדת כיבוי האש**: רצים לעמדה וסורקים אותה. הזכוכית נשברת, הידית נמשכת.
5. **ספרינקלרים**: מים יורדים בכל כיוון שמסובבים אליו את הטלפון, והאש נכבית.

## איך מריצים

המצלמה עובדת רק בכתובת HTTPS, ולכן הכי פשוט להריץ דרך GitHub Pages:

1. בגיטהאב: Settings ← Pages ← Source: Deploy from a branch ← בוחרים את הענף ותיקייה `/ (root)` ← Save.
2. אחרי כדקה המשחק זמין בכתובת `https://yoavpr9.github.io/L05_Yonatan.Ran.Yoav_PhoneGameAR/`.
3. פותחים את הכתובת ב-Chrome בטלפון ומאשרים גישה למצלמה.

להרצה מקומית במחשב: `python3 -m http.server` ואז `http://localhost:8000`.

## סריקת האובייקטים (פעם אחת, בכיתה)

1. במסך הפתיחה לוחצים על **סריקת אובייקטים**.
2. מכוונים את המצלמה אל ידית הדלת, **לוחצים ומחזיקים** את הכפתור "ידית דלת" וזזים מעט סביבה (זוויות ומרחקים שונים) עד שיש 20 דגימות ומעלה.
3. חוזרים על זה עבור **מזגן** ועבור **עמדת כיבוי**.
4. מחזיקים את **רקע** ומצלמים את שאר החדר (קירות, שולחנות, רצפה, אנשים). זה חשוב כדי שהמשחק לא יזהה בטעות.
5. בודקים: השורה "מזהה: ..." באמצע המסך מראה בזמן אמת מה המשחק חושב שהוא רואה.

הסריקות נשמרות בטלפון שסרק. כדי שכל טלפון יזהה את האובייקטים, לוחצים **ייצוא**, ומעלים את הקובץ `scans.json` שירד לתיקייה `scans/` בריפו (במקום הקובץ הריק שקיים שם).

אם המשחק מזהה אובייקט בטעות, או מתקשה לזהות, משנים את `minSimilarity` ב-`CFG` שבראש `js/main.js` (גבוה יותר = מחמיר יותר). במסך הסריקה מוצג אחוז הדמיון בזמן אמת, וזה עוזר לבחור ערך.

כפתור **דלג** במשחק מעביר לשלב הבא גם בלי זיהוי, לגיבוי בזמן הדגמה.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `index.html`, `style.css` | המסכים והעיצוב |
| `js/main.js` | מהלך המשחק והשלבים. בראש הקובץ יש `CFG` עם זמנים ורגישות זיהוי שקל לשנות |
| `js/flames.js` | אש, עשן ואדים ריאליסטיים: שיידרים שמצוירים עם three.js (WebGL) |
| `js/fx.js` | שאר הגרפיקה: חץ, ברקים, גיצים, זכוכית, ספרינקלרים |
| `js/recognizer.js` | זיהוי האובייקטים (MobileNet + השוואה לדגימות שנסרקו) |
| `js/orient.js` | חיישני התנועה, כדי שהאש תישאר "דבוקה" למזגן כשמסובבים את הטלפון |
| `js/audio.js` | צלילים: פעימות לב, אש, זכוכית, אזעקה, מים |
| `vendor/` | TensorFlow.js, מודל MobileNet ו-three.js (כדי שלא תהיה תלות בשרתים חיצוניים) |
| `scans/scans.json` | הסריקות שנטענות כברירת מחדל |
